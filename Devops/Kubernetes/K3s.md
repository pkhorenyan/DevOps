
HA кластер из четырех нод.

### Инициализация первой мастер-ноды (Master-1)

Эта нода запустит встроенную базу данных ETCD.

1. **Запустите установку:**

    ```
    curl -sfL https://get.k3s.io | sh -s - server --cluster-init
    ```

2. **Получите токен кластера** (нужен для подключения остальных нод):

    
    ```
    sudo cat /var/lib/rancher/k3s/server/node-token
    ```
    
    _Сохраните полученную строку (токен)._

---

### Подключение остальных мастер-нод (Master-2 и Master-3)

Выполните команду на **втором** и **третьем** серверах для обеспечения отказоустойчивости.

_Замените `<IP_MASTER_1>` на IP-адрес первой ноды, а `<TOKEN>` на токен из Шага 2._


```
curl -sfL https://get.k3s.io | K3S_TOKEN="<TOKEN>" sh -s - server --server https://<IP_MASTER_1>:6443
```

---

### Подключение воркер-ноды (Worker-1)

Выполните команду на **четвертом** сервере.

_Замените `<IP_MASTER_1>` на IP первой ноды (или балансировщика, если он есть), а `<TOKEN>` на ваш токен._

```
curl -sfL https://get.k3s.io | K3S_TOKEN="<TOKEN>" K3S_URL=https://<IP_MASTER_1>:6443 sh -
```


---

### Проверка кластера

Вернитесь на **Master-1** и проверьте статус всех узлов:

```
sudo kubectl get nodes -o wide
```

Вы должны увидеть все 4 ноды в статусе `Ready` (3 с ролью `control-plane,etcd,master` и 1 с ролью `<none>`).
