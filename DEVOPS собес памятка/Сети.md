## Что происходит при вводе ya.ru в браузере

### 1. Разбор ввода

Браузер понимает, что `ya.ru` — это домен, а не поисковый запрос, и достраивает URL до `https://ya.ru`.

### 2. Поиск IP-адреса (DNS)

Браузеру нужен IP по имени `ya.ru`. Он ищет его по порядку:

- кэш браузера → кэш ОС → файл hosts → DNS-резолвер (обычно провайдера или, например, 8.8.8.8).
- Резолвер при необходимости обходит цепочку: корневые серверы → серверы зоны `.ru` → авторитативный сервер домена `ya.ru`, и возвращает IP.

### 3. Установка TCP-соединения

Браузер открывает TCP-соединение с сервером по IP на порту 443 через three-way handshake (SYN → SYN-ACK → ACK).

### 4. TLS-рукопожатие (HTTPS)

Поскольку `https`, устанавливается шифрованное соединение: обмен сертификатом, проверка его валидности, согласование ключей. После этого весь трафик шифруется.

### 5. HTTP-запрос

Браузер отправляет запрос, обычно `GET / HTTP/2` с заголовками (Host, User-Agent, Cookie и т.д.).

### 6. Обработка на сервере

Запрос доходит до сервера (часто через балансировщики и обратный прокси), тот формирует ответ и возвращает HTTP-ответ: код статуса (200, 301 и т.п.) и тело — HTML.

### 7. Рендеринг страницы

Браузер парсит HTML, строит DOM и CSSOM, догружает подресурсы (CSS, JS, картинки — каждый может потребовать новых DNS/TCP/TLS), выполняет JavaScript и отрисовывает страницу.
